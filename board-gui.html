2D Board GUI Application

A Java-based 2D board application featuring a dynamically generated 32×32 game board with randomized obstacles, rewards, entrance, and exit locations.

Highlights

  • Applied object-oriented programming principles using abstract classes, interfaces, and inheritance to organize board components and behaviors.
  • Implemented Java Swing and AWT for graphical rendering and event-driven user interactions.
  • Used serialization to support saving and loading generated board configurations.
  • Developed logic to prevent overlapping board objects and ensure valid distribution of obstacles and rewards.
