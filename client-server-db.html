Two-Tier Client-Server Database Application

A Java-based two-tier client-server application that connects to MySQL databases using JDBC.

Highlights

  • Created graphical interfaces allowing authenticated users with different permission levels to establish database connections and execute SQL queries and updates.
  • Implemented credential validation, prepared statements, role-based database permissions, and query result processing.
  • Added background transaction logging to track successful database operations, plus a specialized interface for authorized users to monitor database activity.
