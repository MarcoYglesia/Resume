Multithreaded Banking Simulator

A concurrent banking simulation in Java using synchronized, cooperating threads to perform deposits, withdrawals, account transfers, and periodic account audits.

Highlights

  • Implemented thread synchronization and locking mechanisms to safely manage shared bank accounts.
  • Blocked withdrawals when funds were insufficient and coordinated threads when funds became available.
  • Designed atomic transfer and auditing operations requiring simultaneous access to multiple accounts.
  • Implemented transaction monitoring and logging for flagged activity.
